## About me

I'm a final-year **Computer Science & Engineering** student at **BRAC University** in Dhaka. I work across two worlds: **AI research and engineering** (large language models, vision foundation models, representation learning) and **web development** (full-stack JavaScript and PHP apps). I like projects where I have to understand a system all the way down, which is also why my hobby is **building an operating system from scratch**.

### What I'm up to right now

- 🧠 **Finishing my thesis:** [CAEM](https://github.com/aksaN000/caem-thesis), a confidence-aware episodic memory that cuts hallucination in LLMs
- 🖼️ **Planning an image-processing project**, currently in the design stage
- 🌐 **Exploring web development**, sharpening my full-stack skills
- 🤖 **Exploring AI engineering and research**: fine-tuning, retrieval, parameter-efficient adaptation
- 🖥️ **Hobby:** writing my own operating system
